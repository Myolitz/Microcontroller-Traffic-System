# Traffic System Control Project

Material List:
- Arduino UNO R3
- 2x Adafruit VL53L0X Time of Flight Sensors
- 1x Adafruit TCA9548A I2C Multiplexer
- Standard Breadboard
- 2x 220 OHM Resistor
- 2x Traffic Light LED Modules
